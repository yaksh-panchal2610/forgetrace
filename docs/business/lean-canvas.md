# ForgeTrace – Lean Canvas

| Section | Content |
|---|---|
| **1. Problem** | 1. Finding a capable, trustworthy manufacturer takes weeks of calls, emails and visits. <br>2. Quotes arrive in different formats – hard to compare price, lead time and terms. <br>3. Buyers have little visibility once production starts; quality issues are found only on delivery. <br>4. No easy way to prove where a batch came from or to recall it quickly. |
| **Existing alternatives** | Personal contacts, IndiaMART-style directories, trade fairs, WhatsApp/Excel/email, paper inspection reports. |
| **2. Customer segments** | Buyers: hardware startups, SME procurement teams, maintenance departments. Suppliers: MSME machine shops with spare capacity. **Early adopters:** hardware startups ordering 50–5,000 precision parts, and machine shops in one industrial cluster (e.g. Pune / Rajkot / Coimbatore). |
| **3. Unique value proposition** | **“From RFQ to a scannable quality passport — one platform.”** Verified suppliers, comparable quotes, live production status, and every approved batch carries a public QR passport. |
| **High-level concept** | “Marketplace + production tracker + digital quality certificate for contract manufacturing.” |
| **4. Solution** | Capability- and material-based RFQ matching · side-by-side quotation comparison · machine-capacity booking with no double-booking · inspector workflow with automatic tolerance checks · QR product passport · recall & dispute handling. |
| **5. Channels** | Cluster associations & trade fairs (supply side), LinkedIn + SEO + startup communities (demand side), passport pages as viral loop. |
| **6. Revenue streams** | Commission on completed orders, manufacturer subscriptions, traceability add-on, arranged-inspection fee. |
| **7. Cost structure** | Cloud hosting, payment fees, development, verification/ops staff, marketing. Break-even depends on GMV × commission vs. monthly fixed costs (see report §Financials). |
| **8. Key metrics** | RFQs posted / week · quotes per RFQ · RFQ → order conversion · GMV (gross order value) · repeat-buyer rate · % batches passing first inspection · dispute rate · verified manufacturers active per month. |
| **9. Unfair advantage** | Accumulated inspection + passport history per manufacturer (hard to copy trust data); capacity data from real machine calendars enables matching others cannot do. |
